E2T Emoji → Token/Word

Pipeline em Rust que gera o dicionário completo emoji → tokenização e palavra (inglês e pt-BR), a partir de Unicode UTS #51 e tokenizadores HuggingFace.

Código no GitHub ↗ README Experimento Releases AAC AI Lab

Início rápido

git clone https://github.com/aac-ai-lab/e2t.git
cd e2t
make fetch-data
make release
make fetch-emoji-list
make build-dictionary TOKENIZER=data/gpt2-tokenizer.json
make to-words INPUT="🧒 🍎" E2T_LANG=pt-br

O que faz

  • fetch-emoji-list — codepoints Emoji + sequências ZWJ/bandeiras
  • build — CSV dicionário (tokens + word_en + word_pt_br)
  • validate — estatísticas de n_tokens
  • to-words — emoji → palavras (en / pt-br)
